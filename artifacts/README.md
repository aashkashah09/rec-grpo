# artifacts/

Committed, small run outputs: sample JSONL logs, evaluation JSONs, and plots that the
docs/report reference. Every number in the README/report must trace back to a file here
(see `PROJECT_PLAN.md` §1.1).

**Append-only.** Do not delete or rewrite committed artifacts — add new ones
(see `CONVENTIONS.md`, "What NOT to do").

## Contents

- `samples/phase1_tasks_sample.jsonl` — 16 generated tasks with ground truth (Phase 1).
- `phase2/` — regenerated by `make repro-phase2` (stub/CPU-simulator; not real-model numbers):
  - `ope_results.json` / `ope_table.md` — IPS/SNIPS/DM/DR + bootstrap CIs + ESS per policy.
  - `calibration.json` / `calibration_table.md` — replay-A/B: OPE prediction vs realized value.
  - `frontier.json` / `frontier_table.md` + `frontier.png` — realized cost/quality per policy.
  - `breakage.json` / `breakage_table.md` — estimator bias/variance vs shrinking overlap.
  - `calibration.png` — OPE-predicted vs realized (with CIs).
  - `decisions_sample.jsonl` — 50 sample propensity-logged `RouterDecision` records.
